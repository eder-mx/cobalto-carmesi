# `docs/`

Conocimiento procesado del proyecto.

Esta estructura es una **convención de la plantilla**, no una ley universal.
Los agentes deben respetar una estructura válida ya existente y evitar duplicar la misma verdad.

## Estados

`Draft → Ready for Review → Approved`

`Deprecated / Archived = historial, no requisito vigente`

## Áreas

- `00-project/` — contexto, discovery, hechos, decisiones y conflictos.
- `01-strategy/` — producto, oferta, audiencia, alcance, sitemap y estrategia.
- `02-content/` — arquitectura de mensajes, copy, microcopy y conversión.
- `03-design/` — UX/UI, flujos, referencias, exploración visual, responsive y Design System.
- `04-architecture/` — arquitectura técnica, contratos e integraciones.
- `05-development/` — documentación durable de implementación.
- `06-seo-analytics/` — SEO y analítica.
- `07-qa/` — planes, evidencia, defectos y validación.
- `08-devops/` — despliegue y operación.
