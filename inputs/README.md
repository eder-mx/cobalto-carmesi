# `inputs/`

Material bruto del cliente y evidencia de origen.

## Regla principal

Un archivo dentro de `inputs/` **no es automáticamente un requisito aprobado**.

Los agentes deben:

- revisar solo el material relevante para su tarea;
- preservar procedencia;
- no reescribir la fuente para que coincida con una conclusión;
- documentar análisis derivados en `docs/`;
- usar `[POR DEFINIR]` cuando falte información requerida.

Las carpetas son una convención flexible. No es obligatorio que todas tengan contenido.
